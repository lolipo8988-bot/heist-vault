A top-down stealth heist game built for the make.fun
[best heist game bounty](https://make.fun/bounty/best-heist-game-20261122-0559).
One room, the Aldermore private bank's vault floor: cross it past three
patrolling guards and two sweeping cameras, crack $4,000 of loot, and slip
out the getaway door before the alarm meter fills.

Referral code: **7n5rt0bc**

## Play

Open `game/index.html` in desktop Chrome, or serve the folder:

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network requests — every script, sound and pixel is
generated by the code in `game/`.

## Controls

| Key | Action |
| --- | --- |
| WASD / arrows | Move |
| Shift | Sneak (slower, harder to spot) |
| Hold E | Crack loot beside you |
| 1 | Smoke bomb (1 kit) — blinds every cone |
| 2 | EMP pulse (2 kit) — cameras blind 12s |
| Click | Toss a coin — nearest guard goes to look |
| M | Mute |
| R | Retry after a win or a bust |

## The job

- **Routes:** the main hall, the safe room, or the vent shaft along the top
  that sneaks past the hall guard.
- **Tools at a cost:** 3 kit to split between smoke bombs and EMP pulses,
  plus 3 coins to throw.
- **Readable patrols:** guards pause at corners, cones sweep visibly, and
  cameras telegraph their sweep — read them before you move.
- **Fair catches:** being spotted raises the alarm instead of ending the
  run; at 100% the exit seals for an 8-second lockdown. Three grabs by a
  guard and the job is busted.

## Layout

- `game/index.html` — the page, canvas only
- `game/src/config.js` — constants and the level (walls, loot, guards, cameras)
- `game/src/vision.js` — line of sight and vision-cone maths
- `game/src/guards.js` — guard patrol / chase / investigate AI and cameras
- `game/src/game.js` — the heist state machine: alarm, loot, tools, lockdown
- `game/src/render.js` — canvas drawing, cones clipped by walls, HUD
- `game/src/audio.js` — synthesised WebAudio sounds and the midnight pad
- `game/src/input.js` — keyboard and mouse
- `game/src/shots.js` — screenshot scenes played by the real rules
- `game/src/main.js` — boot and frame loop
- `main.ts` — hands `game/` and `screenshots/` to `/output` with a dossier
